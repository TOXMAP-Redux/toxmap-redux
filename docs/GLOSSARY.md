## Acronyms

Entries sorted by **Category**, then alphabetically by **Acronym**.

| Acronym       | Category                    | Full Form                                                                            | Context in TOXMAP                                                                                                                                                                                                                                                                                                                         |
|---------------|-----------------------------|--------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **REST**      | API & Web                   | Representational State Transfer                                                      | API architectural style. All 17 TOXMAP endpoints follow REST conventions over HTTPS with JSON responses.                                                                                                                                                                                                                                  |
| **SLA**       | API & Web                   | Service Level Agreement                                                              | Performance commitment. TOXMAP defines five SLAs in `TOXMAP_API_CONTRACT.md`: viewport query < 500ms p95, facility detail < 200ms p95, chemical autocomplete < 100ms p95, Superfund query < 500ms p95, export streaming < 5 s TTFB.                                                                                                       |
| **DDL**       | Database                    | Data Definition Language                                                             | SQL statements that define schema structure (`CREATE TABLE`, `TRUNCATE`, etc.). The `seed.sql` file contains DDL-equivalent operations that `asyncpg` cannot execute; `psycopg2` is used instead in test fixtures.                                                                                                                        |
| **FK**        | Database                    | Foreign Key                                                                          | Database constraint. `release_events.facility_id` → `facilities.id`, `release_events.chemical_id` → `chemicals.id`.                                                                                                                                                                                                                       |
| **GIST**      | Database                    | Generalized Search Tree                                                              | PostgreSQL/PostGIS index type optimized for multi-dimensional data, including geographic geometries. `CREATE INDEX idx_facilities_location ON facilities USING GIST (location)` enables sub-50ms radius queries on 90K facilities.                                                                                                        |
| **ORM**       | Database                    | Object-Relational Mapper                                                             | Library that maps database rows to programming language objects. SQLAlchemy 2.0 (async) is the ORM; GeoAlchemy2 extends it for PostGIS geometry types.                                                                                                                                                                                    |
| **PK**        | Database                    | Primary Key                                                                          | Database constraint. All core tables use `SERIAL PRIMARY KEY` (`id`).                                                                                                                                                                                                                                                                     |
| **SQL**       | Database                    | Structured Query Language                                                            | Database query language. PostGIS functions are always written in uppercase (`ST_DWithin`, not `st_dwithin`) per project style rules.                                                                                                                                                                                                      |
| **CI/CD**     | DevOps                      | Continuous Integration / Continuous Delivery                                         | Automated build, test, and deploy pipeline. Runs on GitHub Actions; gates include `pytest`, `mypy`, `ruff`, Playwright E2E, Schemathesis contract tests, and the `security.yml` scan suite.                                                                                                                                               |
| **CLI**       | DevOps                      | Command Line Interface                                                               | Terminal-based tool. Relevant in this project for `wrangler` (Cloudflare R2 management) and the ingestion pipeline (`python -m ingestion.tri_ingest --year 2024`).                                                                                                                                                                        |
| **PEP**       | DevOps                      | Python Enhancement Proposal                                                          | Python language/tooling specification documents. `pyproject.toml` uses the PEP 621 format for project metadata.                                                                                                                                                                                                                           |
| **PR**        | DevOps                      | Pull Request                                                                         | GitHub mechanism for proposing code changes. Agent-generated PRs require at least 1 human maintainer approval before merge.                                                                                                                                                                                                               |
| **CAS**       | Environmental Data          | Chemical Abstracts Service (number)                                                  | Unique numeric identifier assigned to every chemical substance, e.g., `7439-92-1` for Lead. Primary key alternative in the `chemicals` table.                                                                                                                                                                                             |
| **ETL**       | Environmental Data          | Extract, Transform, Load                                                             | Data pipeline pattern. The ingestion pipeline (`tri_ingest.py`, `superfund_ingest.py`, `census_ingest.py`) extracts from EPA CSV files, transforms via pandas/geopandas, and loads into PostGIS.                                                                                                                                          |
| **FIPS**      | Environmental Data          | Federal Information Processing Standards (code)                                      | Numeric codes assigned to U.S. states and counties by the U.S. Census Bureau. A 5-digit FIPS code = 2-digit state + 3-digit county (e.g., `48201` = Harris County, TX). Used as the primary key in `census_county`.                                                                                                                       |
| **HRS**       | Environmental Data          | Hazard Ranking System                                                                | EPA's scoring model (0–100) for assessing the relative hazard posed by a Superfund site based on migration pathways (groundwater, surface water, soil, air). Stored as `hrs_score` in `superfund_sites`.                                                                                                                                  |
| **NAICS**     | Environmental Data          | North American Industry Classification System                                        | 6-digit code classifying U.S. business establishments by industry type. Stored in `facilities.naics_code`. Used as a filter parameter in the `/api/v1/facilities` endpoint (e.g., `325` = Chemical Manufacturing sector).                                                                                                                 |
| **NPL**       | Environmental Data          | National Priorities List                                                             | The official list of the nation's most contaminated hazardous waste sites identified by the EPA under CERCLA/Superfund. A site on the NPL has been assessed as posing a significant risk to public health or the environment. Stored as `status = 'NPL'` in `superfund_sites`.                                                            |
| **NPRI**      | Environmental Data          | National Pollutant Release Inventory                                                 | Canadian equivalent of TRI — a federal database of pollutant releases from industrial facilities across Canada. An optional overlay layer in the TOXMAP clone, served from `npri_facilities` table.                                                                                                                                       |
| **SEMS**      | Environmental Data          | Site Enforcement Monitoring System                                                   | EPA's current replacement for CERCLIS (renamed 2013). Tracks Superfund site cleanup progress. URLs in seed data point to `cumulis.epa.gov/supercpad/SiteProfiles/`.                                                                                                                                                                       |
| **TIGER**     | Environmental Data          | Topologically Integrated Geographic Encoding and Referencing                         | U.S. Census Bureau's geographic database of county/tract/district boundaries. The `census_ingest.py` script loads Census TIGER shapefiles into the `census_county` table.                                                                                                                                                                 |
| **TRI**       | Environmental Data          | Toxic Release Inventory                                                              | EPA program (established 1986 under EPCRA) requiring industrial facilities to annually report releases of listed toxic chemicals to the environment. The core dataset of TOXMAP: ~700K records per year, ~4M rows historically (1987–present), published as annual CSV bulk files.                                                        |
| **TRI-MEweb** | Environmental Data          | Toxic Release Inventory Made Easy (web)                                              | EPA's web-based portal for facilities to submit TRI reports and revisions year-round. The existence of this system is why TRI data is NOT read-only — facilities revise submissions continuously, and EPA refreshes the public database at multiple checkpoints per year.                                                                 |
| **ATSDR**     | External Agency / Reference | Agency for Toxic Substances and Disease Registry                                     | CDC sub-agency that publishes ToxFAQs — one-page health summaries for hazardous chemicals. Each chemical in the seed DB carries an `atsdr_url` linking to its ToxFAQ page.                                                                                                                                                                |
| **CDC**       | External Agency / Reference | Centers for Disease Control and Prevention                                           | U.S. public health agency; parent of ATSDR. Referenced for ToxFAQ links (T-08) and mortality co-occurrence data (T-09).                                                                                                                                                                                                                   |
| **EPA**       | External Agency / Reference | Environmental Protection Agency                                                      | U.S. federal agency that collects and publishes TRI data, maintains the NPL/Superfund database, and operates CERCLIS/SEMS. Primary data source for all facility and site data.                                                                                                                                                            |
| **HSDB**      | External Agency / Reference | Hazardous Substances Data Bank                                                       | NLM database of toxicological and chemical safety data. Linked from facility detail pages alongside ATSDR ToxFAQs and PubChem.                                                                                                                                                                                                            |
| **NIH**       | External Agency / Reference | National Institutes of Health                                                        | U.S. biomedical research agency; parent organization of NLM.                                                                                                                                                                                                                                                                              |
| **NLM**       | External Agency / Reference | National Library of Medicine                                                         | NIH sub-agency that originally built and operated TOXMAP (2004–2019). The NLM peer-reviewed articles ([PMC2703818], [PMC4251466]) are authoritative sources for the original system's design and feature set.                                                                                                                             |
| **PMC**       | External Agency / Reference | PubMed Central                                                                       | NIH's free full-text archive of biomedical literature. Two NLM articles documenting the original TOXMAP are archived there: [PMC2703818] (2006) and [PMC4251466] (2015).                                                                                                                                                                  |
| **PubChem**   | External Agency / Reference | PubChem (NIH chemical database)                                                      | NIH database of chemical molecules and their properties. Each seed chemical carries a `pubchem_url` linking to its compound page.                                                                                                                                                                                                         |
| **RIA**       | Frontend & Browser          | Rich Internet Application                                                            | Web application architecture (popular ca. 2010–2015) using browser plugins like Adobe Flash/Flex for desktop-like interaction. The original TOXMAP used this model in its 2013 redesign — now EOL.                                                                                                                                        |
| **SIMD**      | Frontend & Browser          | Single Instruction Multiple Data                                                     | CPU/WebAssembly instruction set that processes multiple data points in parallel. Required by the DuckDB spatial extension when running in WASM mode. Safari iOS < 15 does not support WASM SIMD, triggering automatic fallback to the FastAPI Option B path.                                                                              |
| **WASM**      | Frontend & Browser          | WebAssembly                                                                          | Binary instruction format for a stack-based virtual machine, executable in modern browsers at near-native speed. DuckDB WASM compiles the DuckDB analytical engine to WASM, enabling SQL queries against Parquet files entirely in the browser (ADR-004 Option A).                                                                        |
| **WebGL**     | Frontend & Browser          | Web Graphics Library                                                                 | Browser API for GPU-accelerated 2D/3D rendering. MapLibre GL uses WebGL to render vector map tiles with 100K+ data points without performance degradation.                                                                                                                                                                                |
| **bbox**      | GIS & Mapping               | Bounding Box                                                                         | A rectangle defined by two coordinate pairs (`min_lon, min_lat, max_lon, max_lat`) representing the visible map viewport. Used to scope facility query results to what is currently visible on screen (UCD 2011 finding).                                                                                                                 |
| **EPSG**      | GIS & Mapping               | European Petroleum Survey Group (coordinate system codes)                            | Numerical codes identifying coordinate reference systems. `EPSG:4326` = WGS 84 (longitude/latitude, degrees) — used for all geometry storage. `EPSG:3857` = Web Mercator (meters) — used for `ST_DWithin` distance calculations.                                                                                                          |
| **ESRI**      | GIS & Mapping               | Environmental Systems Research Institute                                             | Proprietary GIS software company. The original TOXMAP ran on ESRI ArcIMS (2004–2012) and ESRI ArcGIS for Server (2013–2019). This clone replaces the ESRI stack entirely with open-source alternatives (PostGIS + MapLibre GL).                                                                                                           |
| **GIS**       | GIS & Mapping               | Geographic Information System                                                        | Software category for capturing, storing, analyzing, and displaying geographic data. The original TOXMAP was described as "a GIS-based gateway" by NLM.                                                                                                                                                                                   |
| **JTS**       | GIS & Mapping               | Java Topology Suite                                                                  | Java geometry library used by Hibernate Spatial and Spring-based GIS stacks (ADR-002). Equivalent to Python's Shapely library.                                                                                                                                                                                                            |
| **OSM**       | GIS & Mapping               | OpenStreetMap                                                                        | Community-maintained global geographic database. Used as the tile source for basemap rendering. Nominatim (the geocoding service) is an OSM project.                                                                                                                                                                                      |
| **PMTiles**   | GIS & Mapping               | Protomaps Tiles                                                                      | A single-file archive format for map tile data created by the Protomaps project. The entire U.S. basemap is packaged as one `.pmtiles` file (~600 MB), hosted on Cloudflare R2 and served directly to MapLibre GL without a tile server.                                                                                                  |
| **WGS84**     | GIS & Mapping               | World Geodetic System 1984                                                           | The standard global coordinate reference system used by GPS. All geometry in TOXMAP is stored in WGS84 (`EPSG:4326` — longitude/latitude in degrees).                                                                                                                                                                                     |
| **ADR**       | Governance                  | Architecture Decision Record                                                         | Numbered documents (`ADR-001` through `ADR-004`) that capture significant technology choices with long-term consequences. Protected files — require RFC + unanimous maintainer approval to change.                                                                                                                                        |
| **CNCF**      | Governance                  | Cloud Native Computing Foundation                                                    | Open-source foundation; governance model referenced as inspiration for `GOVERNANCE.md`.                                                                                                                                                                                                                                                   |
| **DoD**       | Governance                  | Definition of Done                                                                   | Checklist of conditions a story must meet before it is considered complete. Defined per phase in `TOXMAP_DEVELOPMENT_ROADMAP.md`.                                                                                                                                                                                                         |
| **LLM**       | Governance                  | Large Language Model                                                                 | AI language model. Referred to in governance and agents documentation as the backing technology for AI coding agents operating on the codebase.                                                                                                                                                                                           |
| **MVP**       | Governance                  | Minimum Viable Product                                                               | First public release milestone. Corresponds to deployment via ADR-004 Option A (Cloudflare Pages + DuckDB WASM).                                                                                                                                                                                                                          |
| **OSS**       | Governance                  | Open Source Software                                                                 | Software with publicly available source code. A core project goal — the clone replaces ESRI's proprietary stack with OSS equivalents.                                                                                                                                                                                                     |
| **RFC**       | Governance                  | Request for Comments                                                                 | Formal proposal process used for significant changes (new requirements, ADR changes, seed data modifications). Requires a GitHub issue with a minimum discussion period before a vote.                                                                                                                                                    |
| **SEC**       | Governance                  | Security Engineer                                                                    | The project role (and corresponding AI agent, `agents/security-engineer/prompt.md`) responsible for the threat model, dependency scanning, API hardening, browser security headers, and production security posture.                                                                                                                      |
| **CDN**       | Infrastructure              | Content Delivery Network                                                             | Geographically distributed cache network. In production (ADR-004 Option A), Cloudflare Pages and R2 serve all assets via CDN — enabling sub-100ms tile delivery worldwide at $0.                                                                                                                                                          |
| **JRE**       | Infrastructure              | Java Runtime Environment                                                             | Required runtime for Spring Boot fat jars (ADR-002 / Option E). Absent from the recommended ADR-001 Python stack; notable in ADR-004's size comparison (~50–70 MB bundled JRE).                                                                                                                                                           |
| **PaaS**      | Infrastructure              | Platform as a Service                                                                | Cloud hosting model. ADR-004 Option B uses Fly.io (API) + Supabase (database) as free-tier PaaS services.                                                                                                                                                                                                                                 |
| **R2**        | Infrastructure              | Cloudflare R2 (object storage)                                                       | Cloudflare's S3-compatible object storage service. Free tier: 10 GB storage + 10 M reads/month. Used to host Parquet data files and PMTiles in the production (ADR-004 Option A) deployment.                                                                                                                                              |
| **VPS**       | Infrastructure              | Virtual Private Server                                                               | Rented virtual machine. Referenced as a self-hosting option alongside Docker Compose (Option C).                                                                                                                                                                                                                                          |
| **CERCLA**    | Regulatory                  | Comprehensive Environmental Response, Compensation, and Liability Act                | 1980 U.S. law ("Superfund Act") that created the EPA Superfund program for hazardous waste site cleanup. The source of legal authority behind the NPL and Superfund site designations.                                                                                                                                                    |
| **CERCLIS**   | Regulatory                  | Comprehensive Environmental Response, Compensation, and Liability Information System | Former EPA database for Superfund site tracking; renamed SEMS (Site Enforcement Monitoring System) in 2013. Both names appear in seed data URLs.                                                                                                                                                                                          |
| **COEP**      | Security                    | Cross-Origin-Embedder-Policy                                                         | HTTP response header (`Cross-Origin-Embedder-Policy: require-corp`) that prevents a document from loading cross-origin resources unless they explicitly opt in. Required alongside COOP to unlock `SharedArrayBuffer` for DuckDB WASM. Configured in `frontend/public/_headers` (production) and `vite.config.ts` `server.headers` (dev). |
| **COOP**      | Security                    | Cross-Origin-Opener-Policy                                                           | HTTP response header (`Cross-Origin-Opener-Policy: same-origin`) that isolates the browser window from cross-origin documents. Required alongside COEP to enable `SharedArrayBuffer` access — which is needed by DuckDB WASM's multi-threaded mode. Missing this header causes silent DuckDB WASM degradation in production.              |
| **CORS**      | Security                    | Cross-Origin Resource Sharing                                                        | Browser security policy controlling which origins can make requests to a server. Requires specific configuration on the Cloudflare R2 bucket to allow DuckDB WASM to issue HTTP range requests from the browser (see ADR-004 §M-1).                                                                                                       |
| **CSP**       | Security                    | Content Security Policy                                                              | HTTP response header (`Content-Security-Policy`) that controls which scripts, styles, and origins the browser is allowed to load. TOXMAP requires `'wasm-unsafe-eval'` in `script-src` (for DuckDB WASM compilation) and `worker-src 'self' blob:` (for the DuckDB Web Worker). Configured in `frontend/public/_headers`.                 |
| **CVE**       | Security                    | Common Vulnerabilities and Exposures                                                 | Publicly disclosed security vulnerabilities in software packages. `pip-audit` and `npm audit` scan for CVEs in CI on every PR.                                                                                                                                                                                                            |
| **CVSS**      | Security                    | Common Vulnerability Scoring System                                                  | Standardized 0–10 severity score for CVEs. Project policy: patch Critical (≥9.0) within 48 hours, High (7.0–8.9) within 7 days.                                                                                                                                                                                                           |
| **HSTS**      | Security                    | HTTP Strict Transport Security                                                       | HTTP response header (`Strict-Transport-Security: max-age=63072000`) that instructs browsers to only access the site over HTTPS for the specified duration. Configured in `frontend/public/_headers` for the Cloudflare Pages production domain.                                                                                          |
| **SAST**      | Security                    | Static Application Security Testing                                                  | Automated code analysis that finds security vulnerabilities without executing the program. TOXMAP uses `bandit` (Python) and `semgrep` (Python + TypeScript) as SAST tools in `security.yml`.                                                                                                                                             |
| **SRI**       | Security                    | Subresource Integrity                                                                | Browser security feature that verifies downloaded resources have not been tampered with by including a cryptographic hash in the resource reference. TOXMAP uses SRI-format checksums (`sha256-<base64>`) in `manifest.json` to allow the React app to detect tampered Parquet files (story 7.4.3).                                       |
| **SSRF**      | Security                    | Server-Side Request Forgery                                                          | Attack where a server is tricked into making HTTP requests to unintended endpoints. Mitigated in TOXMAP's ingestion scripts by restricting all EPA download URLs to a hardcoded allow-list of `https://www.epa.gov/` and `https://www2.census.gov/` prefixes.                                                                             |
| **T-SEC-xx**  | Security                    | Threat Model Identifier                                                              | Identifier for entries in the TOXMAP threat model (`docs/security/THREAT_MODEL.md`). Used in security code comments, issue tags, and the `FINDINGS_REGISTER.md` to trace a security control back to the threat it mitigates. Example: `T-SEC-01` = resource exhaustion via oversized radius query.                                        |
| **XSS**       | Security                    | Cross-Site Scripting                                                                 | Web security vulnerability where malicious scripts are injected into web pages. Mitigated by React's default HTML escaping; `dangerouslySetInnerHTML` is explicitly banned.                                                                                                                                                               |
| **ATDD**      | Testing                     | Acceptance Test-Driven Development                                                   | Development practice where Gherkin acceptance scenarios are written before implementation. The 57 Gherkin scenarios in `TOXMAP_ACCEPTANCE_TESTS.md` are the project's ATDD artifact set.                                                                                                                                                  |
| **BDD**       | Testing                     | Behavior-Driven Development                                                          | Testing approach using natural-language (Gherkin) scenarios to express expected system behavior. Test runner: `pytest-bdd`.                                                                                                                                                                                                               |
| **E2E**       | Testing                     | End-to-End (testing)                                                                 | Tests that exercise the full system from browser to database. Implemented with Playwright; governed by UX invariants and UCD task scenarios (T-01 through T-09).                                                                                                                                                                          |
| **QA**        | Testing                     | Quality Assurance                                                                    | Testing and validation practice. In TOXMAP, the 57 Gherkin scenarios are the QA contract between product and engineering.                                                                                                                                                                                                                 |
| **UCD**       | UX & Design                 | User-Centered Design, Inc.                                                           | Usability research consultancy commissioned by NLM in 2011 to evaluate the original TOXMAP. Their findings (15 participants, 9 task scenarios) directly shaped 12 non-negotiable UX decisions in ADR-001 and the 57 acceptance test scenarios.                                                                                            |
| **UX**        | UX & Design                 | User Experience                                                                      | Design discipline focused on usability and user satisfaction. The UCD 2011 study produced 10 UX invariants that are tested in every build.                                                                                                                                                                                                |

## Key Terms and Concepts

Entries sorted by **Category**, then alphabetically by **Term**.

| Term                          | Category                    | Definition                                                                                                                                                                                                                                                                                                                                  |
|-------------------------------|-----------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **FastAPI**                   | API & Web                   | Python 3.12 async web framework. Used as the API layer in development/testing (ADR-001) and optionally in production (ADR-004 Option B). Known for automatic OpenAPI schema generation from Pydantic models.                                                                                                                                |
| **HTTP range request**        | API & Web                   | An HTTP feature (`Range: bytes=N-M`) that lets a client download a specific byte range of a file without downloading the whole thing. DuckDB WASM uses this to read only the relevant column chunks from large remote Parquet files, minimizing data transfer.                                                                              |
| **Pydantic**                  | API & Web                   | Python data validation library. FastAPI uses Pydantic models (`schemas/`) to define request parameters and response JSON shapes, enabling automatic OpenAPI documentation and runtime type validation. All user-controlled API parameters must go through Pydantic field validators before reaching the service layer.                      |
| **Alembic**                   | Database                    | Database migration tool for SQLAlchemy. Tracks and applies incremental schema changes to the PostgreSQL database. Migration scripts live in `backend/alembic/`.                                                                                                                                                                             |
| **asyncpg**                   | Database                    | Asynchronous PostgreSQL database driver for Python. Used by the FastAPI application at runtime. Cannot execute multi-statement DDL blocks (like `seed.sql`), which is why `psycopg2` is used separately in test fixtures.                                                                                                                   |
| **H2 Spatial**                | Database                    | H2's embedded in-process relational database with spatial (geometry) support. Covers all PostGIS functions required by TOXMAP (`ST_DWithin`, `ST_Distance`, `ST_Contains`, `ST_Transform`). Analyzed as a potential embedded-DB option in ADR-004 Option E-1.                                                                               |
| **psycopg2**                  | Database                    | Synchronous PostgreSQL driver for Python. Used exclusively in test fixtures (`conftest.py`) for seeding and truncating the test database, because `asyncpg` cannot handle DDL-containing multi-statement SQL blocks.                                                                                                                        |
| **ruff**                      | DevOps                      | Fast Python linter and formatter (Rust-based), replacing `flake8` + `black`. Configured in `pyproject.toml`; runs as `ruff check --fix` (linting) and `ruff format` (formatting) in CI.                                                                                                                                                     |
| **geopandas**                 | Environmental Data          | Python library extending pandas with geospatial data types and operations. Used in the ingestion pipeline for coordinate reprojection and bulk writes to PostGIS (`gdf.to_postgis(...)`).                                                                                                                                                   |
| **ingestion pipeline**        | Environmental Data          | The set of Python scripts (`tri_ingest.py`, `superfund_ingest.py`, `census_ingest.py`, `npri_ingest.py`) that download EPA/Census source files, parse and clean them, and load the results into PostGIS (dev) or generate Parquet files (production).                                                                                       |
| **October freeze**            | Environmental Data          | The authoritative EPA TRI dataset snapshot, frozen each October after the EPA completes its data quality review. The October freeze is the correct source for the primary annual data build. The August preliminary release is incomplete and should be labeled accordingly.                                                                |
| **Parquet**                   | Environmental Data          | Columnar binary file format optimized for analytical queries. TOXMAP's production data pipeline converts EPA TRI CSV files into per-year Parquet files (~150 MB compressed for full US history) hosted on Cloudflare R2 and queried by DuckDB WASM in the browser.                                                                          |
| **Superfund**                 | Environmental Data          | Informal name for both the EPA cleanup program and the sites listed under CERCLA. The TOXMAP clone renders Superfund/NPL sites as diamond-shaped markers (distinct from TRI facility circles) per UCD 2011 icon-ambiguity findings.                                                                                                         |
| **TRI_COLUMN_MAP**            | Environmental Data          | A Python dictionary in `tri_parser.py` that maps raw EPA CSV column header names (which change between reporting years) to normalized internal field names. **Never hardcode EPA column names directly** — always use this map.                                                                                                             |
| **vintage metadata**          | Environmental Data          | Data currency information (EPA snapshot label, build date, record count) stored alongside each Parquet file as a `.meta.json` sidecar. Displayed in the UI so users know whether they are viewing the August preliminary, October freeze, or spring refresh dataset. Omitting this is a **data integrity issue**.                           |
| **PubChem**                   | External Agency / Reference | NIH's free chemical database. Each chemical in TOXMAP carries a `pubchem_url` for the compound page, enabling users to access molecular data and safety information.                                                                                                                                                                        |
| **ToxFAQs**                   | External Agency / Reference | ATSDR's Toxic Substances FAQ series — one-to-two-page plain-language summaries of health effects for specific hazardous chemicals. Linked from the TOXMAP facility detail panel. T-08 tests that the ToxFAQ link for ammonia opens without losing map state.                                                                                |
| **DuckDB WASM**               | Frontend & Browser          | The DuckDB analytical database compiled to WebAssembly, running entirely inside the browser. Enables SQL queries (including spatial functions like `ST_DWithin`) against Parquet files via HTTP range requests — no backend server required. The production deployment target per ADR-004 Option A.                                         |
| **MapLibre GL**               | Frontend & Browser          | Open-source WebGL-based interactive map rendering library (a community fork of Mapbox GL JS v1 with an MIT license). Renders vector map tiles on the GPU, supports 100K+ data points, and implements the color expression ramp needed for TRI release volume color-coding.                                                                  |
| **react-map-gl**              | Frontend & Browser          | React wrapper library around MapLibre GL JS, providing declarative component-based map rendering (`<Map>`, `<Marker>`, `<Layer>`, etc.).                                                                                                                                                                                                    |
| **Recharts**                  | Frontend & Browser          | React-based charting library. Used for two chart types in the facility detail drawer: (1) top-5 chemicals bar chart, (2) 15-year release trend line chart.                                                                                                                                                                                  |
| **service worker**            | Frontend & Browser          | A browser background script that intercepts network requests and can serve cached responses. Used in ADR-004 Option A to cache the WASM binary and Parquet chunks after first load, enabling offline use.                                                                                                                                   |
| **Tailwind CSS**              | Frontend & Browser          | Utility-first CSS framework where styles are applied via pre-built class names (`text-sm`, `flex`, `bg-blue-500`) rather than custom CSS. Used for all frontend styling.                                                                                                                                                                    |
| **Vite**                      | Frontend & Browser          | JavaScript build tool (ESBuild-based) used for the React frontend. Provides fast hot module replacement (HMR) in development and optimized bundles for production.                                                                                                                                                                          |
| **GeoAlchemy2**               | GIS & Mapping               | SQLAlchemy extension providing Python types and functions for PostGIS geometry columns (`GEOMETRY(POINT, 4326)`). Used in ORM models and service-layer queries.                                                                                                                                                                             |
| **Nominatim**                 | GIS & Mapping               | The geocoding service of the OpenStreetMap project.
